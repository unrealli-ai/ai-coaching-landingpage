진행 방식

코칭은 이렇게 진행됩니다.

정리해서 말할 필요 없습니다. 현재 방식 그대로 설명해주시면 됩니다.

01STEP
현재 업무 진단
지금 어떤 업무를 반복하고 있는지 확인합니다. 정리해서 말할 필요 없습니다 — 평소처럼 설명해주시면 됩니다.
02STEP
업무 흐름 분해
업무를 입력 → 처리 → 출력 구조로 나눕니다. 어떤 자료가 들어오고, 어떤 기준으로 처리되고, 어떤 결과물이 나와야 하는지 정리합니다.
03STEP
AI 적용 지점 찾기
AI가 도와줄 수 있는 부분을 구체적으로 표시합니다.
  • 초안 작성 · 요약 · 정리 · 분류
  • 검수 보조 · 아이디어 도출
04STEP
AI vs 자동화 도구 구분
모든 업무가 ChatGPT만으로 해결되지 않습니다. AI로 처리할 부분과 Excel·Power Query·Apps Script 같은 자동화 도구가 더 적합한 부분을 구분합니다.
05STEP
다음 액션 정리

Q제가 가져온 업무도 코칭으로 해결이 가능할까요? +
반복되는 흐름이 있는 업무라면 먼저 진단해볼 수 있습니다. 엑셀 정리, 구글시트 관리, 보고서 작성, 자료 요약, 고객 응대 문구 작성, 반복 입력 작업처럼 일정한 패턴이 있는 업무는 AI나 자동화 도구를 적용할 여지가 있습니다.
Q컴퓨터를 잘 몰라도 가능한가요? +
네. 가능합니다. 오히려 “어디서부터 시작해야 할지 모르겠다”는 분을 위해 만든 코칭입니다. 고객님의 현재 수준에 맞춰 차근히 설명드립니다.
Q미니 진단에서는 어디까지 해주나요? +
미니 진단은 제작이나 세팅 상품이 아닙니다. 반복 업무 1개를 기준으로 AI 적용 가능성, 추천 도구, 자동화 가능 여부, 사람이 검수해야 하는 부분, 다음 액션을 정리합니다.
Q파일을 꼭 공유해야 하나요? +
필수는 아닙니다. 다만 실제 업무 파일이나 화면 캡처가 있으면 더 정확하게 진단할 수 있습니다. 민감한 정보는 가리고 공유해주셔도 됩니다.
